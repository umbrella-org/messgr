# `tickets/` — the ticket-based feature flow

The live board. Every change flows through one artifact per feature: a **ticket** — a
markdown file whose status is the directory it lives in, targeting a registered
child-project via `project:` frontmatter, with an append-only History.

- **Start at [`BOARD.md`](BOARD.md)** — the generated index of every ticket by status.
  It is regenerated by `pickle ticket new`, `pickle ticket move` and `pickle board sync`;
  never edit it by hand.
- **Hand-written planning notes live in [`NOTES.md`](NOTES.md)** — the board cannot
  carry them.
- **The rules, ticket template, and review protocol live in the brine skill:**
  - rules: `.agents/skills/brine/resources/tickets-README.md` (so `§N` references
    resolve there)
  - template: `.agents/skills/brine/resources/TEMPLATE.md`
  - review protocol: `.agents/skills/brine/resources/review-protocol.md`
- **Build target:** every ticket targets a registered child-project (see `../pickle.toml`).

This directory holds **instance data only** (the tickets, the generated board, the notes).
See `../AGENTS.md` for the project configuration and commit policy.
